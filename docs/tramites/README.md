# Trámites

Lo que el código ya no puede resolver. Son los tres permisos de plataforma que
faltan para que el sistema opere de punta a punta, con el texto listo para
presentar.

| Documento | Para qué |
|---|---|
| [meta-app-review.md](meta-app-review.md) | Permisos a solicitar con su justificación, guion del screencast e instrucciones de prueba |
| [politica-de-privacidad.md](politica-de-privacidad.md) | El texto que Meta exige publicar con URL propia |
| [tiktok-y-youtube.md](tiktok-y-youtube.md) | Auditoría de Content Posting y cuota de YouTube Data API |

El orden importa: la verificación del negocio en Meta va antes que el App Review,
y esos dos suman más de un mes. Los de TikTok y YouTube corren en paralelo desde
el primer día.

Mientras los tres avanzan, el sistema funciona: la parrilla, la aprobación, la
publicación en Instagram y en YouTube, y la bandeja manual para lo demás.
